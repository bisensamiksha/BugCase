# Bug Reporter Tool

Source-available, privacy-first browser extension that captures a downloadable bug-report ZIP. Companion GitHub Pages dashboard renders the ZIP entirely in the browser. No backend, no telemetry.

The project is currently in foundation setup; application code will be added ticket by ticket.
