# Chrome Web Store — generated promo assets

These PNGs are **generated** from the SVG masters in `design/`, never hand-edited. They are the
committed build artifacts (like the extension icons); regenerate after editing a master:

```bash
pnpm store:assets
```

| Asset                        | Size     | Master                                                                               | Store field                          |
| ---------------------------- | -------- | ------------------------------------------------------------------------------------ | ------------------------------------ |
| `promo-tile-440x280.png`     | 440×280  | [`../../../design/store-promo-small.svg`](../../../design/store-promo-small.svg)     | Chrome small promo tile              |
| `promo-marquee-1400x560.png` | 1400×560 | [`../../../design/store-promo-marquee.svg`](../../../design/store-promo-marquee.svg) | Chrome marquee promo tile (optional) |

The Edge 300×300 store logo is generated by the same script into
[`../../edge/assets/store-logo-300x300.png`](../../edge/assets/store-logo-300x300.png).

- Regeneration uses headless Chromium via Playwright (already a dev dependency — no extra image
  toolchain), so `scripts/generate-store-assets.mjs` needs no new packages.
- Dimensions are guarded by `packages/extension/src/packaging/store-assets.test.ts`.
- App **screenshots** are captured by hand — see [`../screenshots/README.md`](../screenshots/README.md).
